# clear-writing の根拠

skill の内部資料。**書いた文章には出さない。** 実行時に読む必要はなく、規範を見直すときに参照する。

| 採用した手順 | 裏付け |
|---|---|
| 階層アウトラインを作ってから書く | Kellogg。順不同の書き出しは質を変えず、必要な順に並べると改善し、階層アウトラインが最高品質 |
| 評価を上流の工程から始める | Sommers (1980)。熟達した筆者は議論の形を見直し、未熟な筆者は語の入れ替えに終始する |
| 段階の行き来を許す | Flower & Hayes (1981)。計画・執筆・推敲は再帰的で、固定の順序では進まない |
| 目的を先に一文で決める | 木下是雄『理科系の作文技術』の目標規定文 |
| 認知フレームを読む前に作る | Bransford & Johnson (1972)。題を先に与えた群だけ理解・再生が向上し、後から与えた群には効果なし |
| 中心文を冒頭に置く | 木下是雄の重点先行主義。NN/g の視線計測（F 型の読み方、長文の下端に到達しない） |
| 既知→新情報の順・文末の強調位置 | Haviland & Clark (1974) の given-new contract。Gopen & Swan (1990) の topic position / stress position |
| 否定形を肯定形に | Clark & Chase (1972) 以来、否定文は読む時間が長く誤り率も高い |
| 調子に頼らない | Kruger, Epley, Parker & Ng (2005)。送り手は調子が伝わる度合いを過大評価する |
| 明示度を読者層で変える | McNamara & Kintsch (1996) の reverse cohesion effect、O'Reilly & McNamara (2007) |
| 見出し・箇条書き・強調 | signaling のメタ分析（学習成果で d ≈ .38）。Lorch らの実験で、見出しは話題数を増やす一方、各話題の中身の記憶は減らす |
| 修飾の順序・読点の二原則 | 本多勝一『日本語の作文技術』 |
| 事実と意見の書き分け | 木下是雄『理科系の作文技術』 |
| 短文化の限界 | 文長のみを基準にした単純化は接続を落として結束を壊し、理解を下げるとの報告 |
| 翻訳調・LLM 口調の排除 | k16shikano が公開している japanese-tech-writing の gist（Unlicense）から、頻出するものを抜粋。この環境に skill としては入っていない |
| 主名詞の前に修飾節を積まない | Martínez, Mollica & Gibson (2022, Cognition)。契約書の処理困難は専門概念ではなく書き方に由来し、中央埋め込みが想起を最も阻害する。法律家でも同じ |
| 前提知識が低い層ほど一文を短く | 「やさしい日本語」（佐藤和之ら）。一文をひらがな 24 字以内にすると来日一年以上の外国人の八割以上が理解 |
| 平易化そのものの効果 | Masson (1994) の契約書実験ほか。陪審説示の平易化で理解が平均 41% 改善、様式の目的理解が 23% → 70% に改善した事例がある |
| 中間生成物を出力にも添える | 単一ターンで計画・要点・構成を書いてから本文を書かせる手法で、ROUGE-Lsum +2.5%、人手の対比較で勝敗比 3.60、構成・関連性・検証可能性が改善（Integrating Planning into Single-Turn Long-Form Text Generation, arXiv:2410.06203） |
| 各工程で決めた時点のものを持ってくる | Turpin et al. (2023)。事後に書いた説明は本当の理由を表さず、後付けの正当化になりうる。本文を書いてから前提を書き起こすと、辻褄合わせになり検証に使えない |
| 確認項目を各工程の直後に置く | Gawande / WHO の手術安全チェックリスト。項目を工程の切れ目（pause point）に分けて置く形式が定着し、全項目を末尾に集約する形は採られていない。手戻りは早い段階で捕まえるほど安い |

## 過信しない点

- 階層アウトラインの効果は、筆者が題材について既に考えを固めている場合に小さくなる。
  慣れた型の短い文章では、工程5・6 を頭の中で済ませてよい
- 「読む前に枠組みを与える」系の手法のメタ分析は、全体として促進的だが効果は一貫せず、読者の
  前提知識に依存する。一文で済むので常に置くが、これだけで理解が保証されるとは考えない
- signaling の効果量は小〜中程度で、見出しには話題数と中身のトレードオフがある
- 平易化の効果は、どの推奨を採るか・対象が誰か・理解をどう測るかで大きく変わる。
  「平易に書けば必ず伝わる」とは考えない
- 「やさしい日本語」の 24 字という数値は非母語話者と災害情報が対象。母語話者向けの社内文書に
  そのまま持ち込まない
- **段階化そのものが質を上げるとは限らない。** 100 超の論文と 20 データセット・14 モデルのメタ分析で、
  chain-of-thought の利得は記号推論 +14.2%、数学 +12.3% に集中し、それ以外のタスクでは小さかった
  （Sprague et al., ICLR 2025）。文章作成は非推論タスクなので、この skill の段階化は推論の利得ではなく、
  外れた前提を人間が訂正できるようにするために置いている。Plan-and-Write 系も、情報の圧縮には効く一方
  創作では一貫した利得が出なかったという報告がある
- 可読性指標（Flesch-Kincaid など）は評価に入れない。文と語の長さしか見ておらず、人間の評価と
  相関しなかった報告もあり、日本語には直接使えない

## 未検証の推論

- **七つという工程の切り方**: 上流から作って上流から直すこと自体は Kellogg と Sommers が支える。
  ただし「読者 / 目的 / 素材 / 文意 / 構造 / 節 / 文」という七分割そのものは設計判断で、この粒度が
  最適だと示した研究は確認していない。工程を一つにつきアウトプット一つとしたのは、
  読者・目的・素材を一工程に束ねていたとき、最後に置いた素材の仕分けだけ条件が抜け落ちた
  （2026-09-13）という自分の失敗から。分け方を変える提案は、研究との矛盾ではなく使い勝手で評価する
- **中央埋め込みの日本語への適用**: Martínez らの研究は英語の契約書が対象で、日本語での追試は
  確認していない。日本語は左枝分かれなので連体修飾の積み重ねが同型の負荷を生むと考えているが、
  これは推論である
