画像で読むページ数がそのまま使用量になるため、読む対象を裏づけスライドだけに絞る。

1. `{{TXT}}` を読む。ページ区切りは改ページ文字（`\f`）で、n 個目のブロックが n ページ目にあたる。
   図の中の文字は抜けていることがあるので、**話の流れをつかむための目次として使う**。
2. テキストだけを根拠にメッセージの候補を 5〜8 個立て、それぞれについて
   「裏づけになりそうなページ番号」を 1〜3 個ずつ挙げる。
3. **そこで挙げたページだけ**を Read ツールの `pages` 引数で見る。
   合計 {{MAX_VISUAL}} ページ以内に収める。数字・図・強調はここで確認する。
4. 見た結果メッセージがずれていたら直す。必要なら追加で数ページ見てよいが、
   {{MAX_VISUAL}} ページの上限は守る。テキストで足りるところを画像で読み直さない。
